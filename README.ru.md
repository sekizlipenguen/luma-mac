# Luma для macOS

**Понимайте, что делает Mac. Находите, что занимает место. Очищайте с контролем.**

Luma — нативное приложение SwiftUI для мониторинга системы, анализа хранилища и обслуживания Mac. Работает локально, без аккаунта, подписки, рекламы и телеметрии.

**Личное и коммерческое использование бесплатно и не ограничено:** без лимитов устройств, пользователей, функций или времени. Исходный код можно изучать и компилировать без изменений. Изменение собственной копии и создание производных версий требуют письменного разрешения. [Лицензия](LICENSE).

## Возможности

- **Обзор и память:** CPU, давление памяти, сжатая память, swap, диск, сеть, батарея и счётчики энергии процессов. Без фиктивной очистки RAM.
- **Процессы CPU:** группировка приложений и вспомогательных процессов, поиск, раскрытие подробностей и обычное завершение приложения после подтверждения.
- **Хранилище и Finder:** тома, размеры папок и большие файлы; измерение папки в Luma через Finder или Службы.
- **Дубликаты:** сравнение содержимого с SHA-256 и проверка совпадений до удаления.
- **Очистка и разработка:** разрешённые правила и поддерживаемые кеши разработки; оценка, проверка, подтверждение и перенос в Корзину по умолчанию.
- **Приложения и запуск:** список приложений, отдельно выбираемые связанные файлы, объекты входа и LaunchAgents. Системные LaunchDaemons доступны только для просмотра.
- **Симуляторы:** остановка симуляторов iOS и эмуляторов Android после подтверждения; физические устройства исключены, данные устройств не стираются.
- **Диск и безопасность:** SMART при наличии; FileVault, брандмауэр, Gatekeeper, SIP и разрешения со ссылками на настройки. Это не антивирус.
- **Обслуживание, расписание и история:** поддерживаемые действия и локальные записи. Расписание открывает Luma, а не удаляет файлы незаметно.

## Безопасность и конфиденциальность

Очистка проходит через `CleanupRule` и `PathSafety`. Системные области, связки ключей, Mail, Messages и ключи SSH исключены. Пробные запуски не меняют файлы. Пока файлы остаются в Корзине, их можно восстановить через Finder.

Основные функции работают локально. Недоступные данные обозначаются явно: температура без поддерживаемого публичного API, отсутствие батареи на настольных Mac и зависимость SMART от диска. [Модель безопасности](Docs/Safety-Model.md).

## Установка и требования

**macOS 15 или новее.** Официальные пакеты приложения после публикации доступны в [Releases](https://github.com/sekizlipenguen/luma-mac/releases). Для каждого выпуска проверьте архитектуру, подпись и нотариальное заверение Apple. ZIP исходного кода не является готовым приложением. Распакуйте ZIP приложения и перенесите `Luma.app` в Программы.

Для защищённых папок Library предоставьте Полный доступ к диску в Системные настройки → Конфиденциальность и безопасность. Без разрешения недоступные места пропускаются. Расширение Finder можно включить в настройках расширений macOS. Для iOS нужны инструменты командной строки Xcode; для Android — инструменты SDK, включая `adb`.

## Сборка без изменения исходного кода

Нужны Xcode с поддержкой Swift 6, SDK macOS 15 или новее и XcodeGen. Команда создаёт локальную сборку с подписью ad hoc, без подписи Developer ID и нотариального заверения.

```bash
git clone https://github.com/sekizlipenguen/luma-mac.git
cd luma-mac
brew install xcodegen
xcodegen generate
xcodebuild -project Luma.xcodeproj -scheme Luma -configuration Release -derivedDataPath build CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build
```

Результат: `build/Build/Products/Release/Luma.app`.
