# Security reports

Report issues that could bypass path protections, perform unintended file
changes, or expose private information.

When enabled, use [GitHub private vulnerability reporting](https://github.com/sekizlipenguen/luma-mac/security/advisories/new).
If unavailable, open an Issue requesting a private channel without posting
vulnerability details, exploits, personal paths, or sensitive data.

Include the Luma version, macOS version, affected feature, expected and observed
behavior, and reproduction steps with disposable test files. Do not include
credentials, private files, personal IPs, or identifying screenshots. Never
test destructive actions against real user data.

There is no guaranteed response time or promised support period. When fixes
are released, use the latest version and review its release notes.
