# Luma لنظام macOS

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [Русский](README.ru.md) · [العربية](README.ar.md)

**افهم ما يفعله جهاز Mac، واعرف ما يشغل المساحة، ونظّف بعد المراجعة.**

Luma تطبيق أصلي مبني باستخدام SwiftUI لمراقبة النظام وتحليل التخزين وصيانة Mac. يعمل محليًا دون حساب أو اشتراك أو إعلانات أو تتبع عن بُعد.

**الاستخدام الشخصي والتجاري مجاني وغير محدود:** لا حدود لعدد الأجهزة أو المستخدمين أو الميزات أو مدة الاستخدام. يمكنك الاطلاع على المصدر وتجميعه دون تعديل. تعديل نسختك الخاصة أو إنشاء إصدارات مشتقة يتطلب إذنًا كتابيًا. [الترخيص](LICENSE).

## الميزات

- **الملخص والذاكرة:** استخدام CPU وضغط الذاكرة والذاكرة المضغوطة وswap والقرص والشبكة والبطارية وعدادات طاقة العمليات. لا يوجد تنظيف وهمي للذاكرة.
- **عمليات CPU:** تجميع التطبيقات والعمليات المساعدة، والبحث وعرض التفاصيل، وإنهاء التطبيق بشكل عادي بعد التأكيد.
- **التخزين وFinder:** فحص وحدات التخزين وأحجام المجلدات والملفات الكبيرة؛ قياس حجم المجلد داخل Luma من Finder أو الخدمات.
- **الملفات المكررة:** مقارنة المحتوى باستخدام SHA-256 ومراجعة النتائج قبل الإزالة.
- **التنظيف وأدوات التطوير:** قواعد مسموح بها وذاكرة تخزين مؤقت مدعومة، مع تقدير ومراجعة وتأكيد؛ النقل إلى سلة المهملات هو الخيار الافتراضي.
- **التطبيقات وبدء التشغيل:** التطبيقات المثبتة والملفات المرتبطة القابلة للاختيار فرديًا وعناصر تسجيل الدخول وLaunchAgents. ملفات LaunchDaemons الخاصة بالنظام للعرض فقط.
- **المحاكيات:** إيقاف محاكيات iOS وAndroid بعد التأكيد؛ تُستثنى الأجهزة الفعلية ولا تُمسح بيانات الأجهزة.
- **القرص والأمان:** SMART عند توفره، وFileVault وجدار الحماية وGatekeeper وSIP والأذونات مع روابط الإعدادات. التطبيق ليس مضاد فيروسات.
- **الصيانة والجدولة والسجل:** إجراءات مدعومة وسجلات محلية. الجدولة تفتح Luma ولا تحذف الملفات بصمت.

## الأمان والخصوصية

تمر عمليات التنظيف عبر `CleanupRule` و`PathSafety`. تُستثنى مناطق النظام وسلاسل المفاتيح وMail وMessages ومفاتيح SSH. التشغيل التجريبي لا يغيّر الملفات. يمكن استعادة الملفات من Finder ما دامت في سلة المهملات.

الميزات الأساسية محلية. تُوضَّح البيانات غير المتاحة، مثل الحرارة دون واجهة API عامة مدعومة، أو غياب البطارية على أجهزة Mac المكتبية، أو اعتماد SMART على القرص. [نموذج الأمان](Docs/Safety-Model.md).

## التثبيت والمتطلبات

**macOS 15 أو أحدث.** تظهر حزم التطبيق الرسمية بعد نشرها في [Releases](https://github.com/sekizlipenguen/luma-mac/releases). راجع المعمارية والتوقيع وتصديق Apple لكل إصدار. ملف ZIP للمصدر ليس تطبيقًا جاهزًا للتثبيت. فك ضغط حزمة التطبيق وانقل `Luma.app` إلى التطبيقات.

للوصول إلى مجلدات Library المحمية، امنح الوصول الكامل إلى القرص من إعدادات النظام ← الخصوصية والأمان. دون الإذن تُتخطّى المواقع غير المتاحة. يمكن تفعيل إضافة Finder من إعدادات إضافات macOS. يحتاج iOS إلى أدوات سطر أوامر Xcode، ويحتاج Android إلى أدوات SDK بما فيها `adb`.

## البناء دون تعديل المصدر

يلزم Xcode يدعم Swift 6 وSDK لنظام macOS 15 أو أحدث، بالإضافة إلى XcodeGen. ينتج الأمر بناءً بتوقيع ad hoc للاستخدام المحلي، دون توقيع Developer ID أو تصديق Apple.

```bash
git clone https://github.com/sekizlipenguen/luma-mac.git
cd luma-mac
brew install xcodegen
xcodegen generate
xcodebuild -project Luma.xcodeproj -scheme Luma -configuration Release -derivedDataPath build CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build
```

الناتج: `build/Build/Products/Release/Luma.app`.
